# Security

Report suspected vulnerabilities through this repository's [private vulnerability reporting](https://github.com/HallelujahHomeChurch/hhc-web-api/security/advisories/new).

Include the affected revision, a minimal synthetic reproduction, and the expected security boundary. Do not put credentials, personal information, private media, production diagnostics, or account identifiers in a public issue or pull request.

This repository contains application source and synthetic fixtures. Production configuration and historical operational evidence are maintained privately. Publication of the source does not grant access to deployed services or protected content.

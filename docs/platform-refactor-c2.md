# C2 candidate: verified Asset completion and owner reads

Issue #15; stacked on C1 #14. Producer candidate Asset AS4 `498165f1231ff6082c33d2ebcfc5b5d7aabd13ab` (wire introduced in `95e7fdee24f1419d0b9c434744d200760a73ba7a`) includes AS5. Planning revision `ca186f025d021c5e2cfe849c05cafcc3f20ada57`.

The shared private Asset decoder accepts the legacy response only when the optional field is absent. Explicit readiness must use version 1, a known state, and agree with the existing lifecycle fields; unknown/null or contradictory evidence fails closed before publication, grants, progress and worker readers. Safety evidence has a closed known-kind set. Original-source helpers reject trusted derivation as a malware scan. Readiness does not authorize a business operation.

`ASSET_TRUSTED_DERIVATION_ENABLED` defaults false and requires verified `hhc-web-bulletin-worker` identity. The watermark worker passes the ETag from the downloaded immutable source, alongside the already verified source SHA-256 and output byte evidence, to the ordinary completion path's approved `bulletin-watermark` version `1` proof. A response must explicitly report ready and trusted-derived evidence; an ordinary completion, missing evidence or producer failure never falls back to the narrow adapter. With the flag off, the existing narrow adapter remains available.

`ASSET_OWNER_CONTENT_ENABLED` defaults false and requires verified CMS API identity. The owner reader validates exact issue, locale, purpose, namespace, private visibility, digest and scanned metadata before requesting the hash/owner-bound stream. The illustration consumer retains its existing PNG byte/dimension/hash limits and zh-Hant product scope; the reusable owner read also accepts the existing en and zh-Hans source classes. This does not expand extractor/watermark principal scopes or replace user download grants. Their existing service-grant paths remain intact. No browser private route is introduced.

Deploy compatible AS4/AS5 producers with capability scopes unset, then the CMS decoder/caller with flags off. Verify exact identity, per-principal scopes and fixed candidate integration before enabling either capability. Disabling returns to the compatible narrow adapter, without relaxing scan or ownership checks. Structured proof requires the AS4-compatible Asset writer floor; do not roll Asset back below it. No flag, provider or production runtime has been changed.

Local tests cover old producer/new consumer, new producer/legacy adapter, explicit ready/pending/rejected and malformed versions, actual scoped transport, original-vs-derived evidence, en/zh-Hant metadata ownership and exact source proof/replay. The opt-in `TestC2ActualAssetProducer` uses a fixed local Asset handler, PostgreSQL, synthetic TLS/JWT and Blob fixture; it does not run the real watermark renderer or establish provider/live readiness. Required CI and native renderer lanes remain separate gates.
